# laravel blade template engine 

  1. laravel provides blade template engine 
  2. laravel create a view via blade
  3. laravel load view 

     **resource=>views=>welcome.blade.php**

  4. blade templates load views file or save file via .blade.php
  5. blade templates used via laravel  routing => routing is used to load your url 
  6. **resource=>views=>welcome.blade.php**
  7. blade templates integration follow a inheritance concepts
